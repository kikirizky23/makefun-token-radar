How this board is built — formula, peers, product-line rule

The formula

implied_value_usd = round(tvl_usd × categoryMultiple × growth × maturity × productLine)

  • Category multiple — peer median per category, shrunk toward the global median: (n · median_category + 3 · globalMultiple) / (n + 3). Categories with no tokenized peers use the global median ×0.1691.
  • Growth — 1 + 0.5 · clamp(change_7d, −60, 120) / 100 (no 7d data → 1.0; range 0.7–1.6).
  • Maturity — 0.65 + 0.35 · (1 − exp(−age_days / 730)); older protocols score closer to 1.0.
  • Product line — ×0.5 when the row is only one product line of a larger protocol (last word of the name in {curator, prime, exchange, gateway, perps, spot, vaults, strategies, management}, or a stablecoin-product name such as thUSD/avUSD or USDCx). Only part of the protocol TVL belongs to that line, so valuing the whole TVL as the product's own would overstate it.
  • Peers — 143 protocols that already have a token: peer ratio = min(mcap_usd / tvl_usd, 1.5); mcap_usd = 0 counts as ratio 0. Global multiple = median of all peer ratios.
